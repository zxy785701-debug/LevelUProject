版本：答题导航与头像操作 v5.3 / 2026-10-12。

新增分段题号与「上一题／下一题」，可切换任意题，已提交答案锁定，全部作答后结算；头像提供查看、保存图片与更换入口。页面返回恢复滚动位置，首页明确标注金币余额。进阶新关卡每题答对奖励为 15 XP、3 金币，入门仍为 10 XP、2 金币；历史关卡保留原规则。原型可演示对应操作，正式微信选择头像与相册保存由 `frontend/` 的原生接口完成。

首页「生成我的关卡」、历史空态「开始我的第一关」及其他同类主操作按钮统一使用蓝色 `#336AE8`，并同步到 `frontend/`。次要按钮保留白色、禁用按钮保留灰色、危险操作保留警示色；布局与黄色标题装饰保持原样。全部 HTML 入口已更新共享样式版本。

底部布局验收可打开 `07-footer-review.html`，按业务模块与名称筛选 55 个页面和状态。以用户调整后的错题本 E 版为基准：底部主按钮蓝色、标题黄色划线、清晰的字级和辅助说明。作答后出现的按钮、暂停底部弹层及通用确认弹窗也已同步。

错题本的「今天复习」为浅红标签；列表移除重复书本图标，说明左侧加黄色竖线，题量与时长中的数字加粗。标题黄线保留用户保存的 **8px 粗细、3px 下移**。统一参数在 `assets/refined-footer.css` 文件开头，字号与黄线参数都有中文注释。

直接使用浏览器打开 `index.html`。请保留整个 `prototype` 文件夹的目录结构，页面共享 `assets` 中的样式、交互和图片，不需要安装依赖或构建。若浏览器限制本地文件下载或会话存储，可通过普通静态服务预览。

## 建议体验路径

1. 目录 → “体验完整学习流程”。输入区可编辑、粘贴长文本，或选择示例。
2. 生成 → 本轮准备 → “开始这一关”。默认 5 题，也可在出题设置选择 3 题。原型使用固定 HTTP 示例题，不调用 AI。
3. 单选/判断选择后立即讲解，多选需要提交；答案锁定后继续。五题结束统计实际正确率、用时、XP 和金币。
4. 答题左上角返回可暂停；保存离开后，从首页的继续学习入口恢复。本次会话内刷新已答题页面不会重复获得奖励。
5. 结算 → 报告 → 分享。可下载实际的 PNG 海报；设置中可导出 CSV 学习记录，周期报告可导出 TXT。
6. 各分组还可演示材料选择、文件夹保存、错题重温、筛选、模拟登录、订单结果、权限替代入口和数据确认。

## 三个学习搭子

- 小U：U 形书灵，欢迎、输入、解析、知识讲解与报告。
- 笔仔：涂鸦铅笔，答题、连击、通关、挑战与成就。
- 团团：纸团探险家，复盘、知识库、空白与异常恢复。

三个透明原图保留在 `assets`；没有复制参考原型的角色、CSS、布局或文案。参考 39 个业务页面均在本套原型覆盖。

## 演示范围

AI 获取/解析/生成、微信授权与好友分享、支付、语音识别和小程序码没有接入真实服务。文件选择只显示本地信息，不上传。语音题的“播报”可使用浏览器自身的语音能力；“录音”只模拟识别文本，不请求麦克风。

价格、解析额度、正式套餐权益均待确认。每道新关卡题正确 +10 XP / +2 金币，答错不扣已有奖励；连击、重试、恢复与错题重温不重复发奖。装扮不影响 PK 公平性。

完整体验后的统计来自实际选择；画廊、周期分析、好友和订单使用示例数据。海报是固定的 HTTP 学习收获示例，不含真实小程序码。页面里输入和偏好临时保存在浏览器会话中，不作为后端存储。
