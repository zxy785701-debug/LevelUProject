# 错题本 D 版 HTML 调整页

打开同目录的 **错题本-D版调整.html**，即可调整字体与黄色线条。

这个 HTML 已包含吉祥物图片，不需要安装依赖，也不需要附带 assets 文件夹。桌面端在右侧调节；手机端调节面板位于页面预览下方。

## 推荐操作

1. 拖动滑块，或直接输入数值，立即查看变化。
2. 常用字号、黄色线条默认展开；其他字号及留白设置可展开调整。
3. 点击“只看页面”，暂时收起调节工具。
4. 调好后点击 **保存调整后的 HTML**。下载文件名为“错题本-D版-我的调整-日期时间.html”。
5. 把这个下载文件发回，里面已经包含最终参数。

“恢复初始值”恢复当前这份 HTML 顶部写入的参数。浏览器中上次调整会尽量保留；发送最终结果时，请使用页面内的保存按钮。

## 直接修改源码

源码顶部的 `:root` 已有逐行中文注释。可以直接修改以下变量后保存、刷新。

| 变量 | 当前值 | 修改内容 |
| --- | --- | --- |
| `--title-font-size` | 28px | 主标题字号 |
| `--subtitle-font-size` | 13px | 副标题字号 |
| `--question-font-size` | 16px | 知识点标题字号 |
| `--meta-font-size` | 12px | 题型、主题和作答时间字号 |
| `--badge-font-size` | 11px | 今天复习标签字号 |
| `--note-font-size` | 12px | 黄色竖线旁说明字号 |
| `--summary-font-size` | 12px | 题量和预计时间字号 |
| `--button-font-size` | 16px | 开始复习按钮字号 |
| `--underline-height` | 2px | 标题黄色下划线粗细 |
| `--underline-offset` | 3px | 下划线向下偏移，越大越低 |
| `--note-line-width` | 2px | 说明旁黄色竖线粗细 |
| `--subtitle-gap` | 18px | 标题和副标题的间距 |
| `--question-row-height` | 82px | 每行题目的最小高度 |

例如，将题目信息改为 11.5px、下划线改为 1.5px：

```css
--meta-font-size: 11.5px;
--underline-height: 1.5px;
```

这是一份独立的 D 版样式调整页，尚未修改完整原型的共享样式或业务页面。页面中的答题和筛选按钮仅作视觉预览。

已验证：13 个调节项、数字输入、滑块键盘操作、刷新保留、恢复初始值、仅预览切换；320 / 390 / 820 / 1280px 无横向溢出。

导出内容通过 Blob 捕获并重新加载，验证字号和黄线参数写入顶部 CSS，吉祥物可显示，且无外部脚本、字体或图片依赖。自动化浏览器的原生下载通道会中断连接，因此导出内容采用上述方式验证；正常浏览器使用标准 HTML 下载链接保存。
