## 发现的问题与修复证据

1. 初次本地环境将固定维度以字符串读入 Literal[int]。增加只允许字符串 `1024` 的环境转换；`33-config-env-red` → `33-config-env-green-final`（12 passed）。
2. LangChain 默认缓存异步客户端跨越执行器多次 `asyncio.run`，导致后续真实请求 RuntimeError。按 Context7 官方 `http_async_client` 接口，将每个任务的 HTTPX 客户端创建、共享及关闭限制在同一异步循环。`43-model-transport-red`（5 failed）→ GREEN（5 passed）；49 复核正常。
3. MySQL 秒精度可能把释放时间舍入到下一秒，造成执行器立即重启时误报占用。释放时间截断到秒；`47-worker-release-red` → `47-worker-boundaries-green`（26 passed）。

这些失败日志与后续修复结果均保留，不以多次重跑掩盖失败。本报告证明列出的固定样本结果，人工微信操作记录另外登记。
