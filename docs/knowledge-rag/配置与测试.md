# 知识库配置与测试

知识库配置按需读取，独立于原应用的 Settings。默认 `KNOWLEDGE_ENABLED=false`。缺少凭证、错误目录、可选依赖缺失或参数不合法时只报告知识库不可用；健康检查和旧功能继续可用。状态检查不创建目录、不打开 Chroma、不探测收费服务。

百炼使用北京地域，独立设置 `KNOWLEDGE_EMBEDDING_API_KEY` 和 `KNOWLEDGE_EMBEDDING_BASE_URL`。Base URL 从本人百炼控制台复制，格式为 `https://业务空间.cn-beijing.maas.aliyuncs.com/api/v1`；不要填写兼容 OpenAI 路径。本实现采用原生接口，模型 `text-embedding-v4`、1024 维、cosine。密钥不提交 Git、不放前端、不输出日志。原 DeepSeek/Tavily 凭据保持原有配置。

存储默认使用后端下被 Git 忽略的 knowledge-data，可用 `KNOWLEDGE_STORAGE_ROOT` 指定绝对私有目录。不得设置为公开静态资源目录。API 不打开本地索引；启用前需完成增量迁移并启动独立执行器。关闭入口后仍须保留历史快照读取和清理执行能力。

初始额度：100 份资料、500 万正文字、每日 20 次导入、20 次问答、20 万 Embedding 输入 Token；向量化不扣关卡次数。Embedding 模型和维度变更须新增配置及完整重建，本版本不接受任意维度切换。
