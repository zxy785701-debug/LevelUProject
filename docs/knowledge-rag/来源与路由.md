## 路由与公开参数

每次先执行受服务端资料版本约束的 knowledge_search；只接受 query/maximum，不接受用户、资料 ID、集合或任意 filter。关闭联网或缺少 Tavily 时仍可使用知识库。新请求的联网默认值在问答/范围 DTO 中定义，旧材料默认值不变。

联网前另用只接收原始目标的模型请求规划 PublicWebPlan；不加入文件、文件名、账号或历史。服务端复核文件名、账号标识及私有标识，不能安全概括时放弃自动联网。后续 Agent 只能逐字段使用已批准的 SearchParameters；Extract 只接受用户给出的公开 URL 或真实公开搜索返回的 URL，定向查询也受公开计划限制。资料中的指令无法放宽这些约束。

参数沿用官方 Search/Extract DTO、内容模式、深度、条数、日期和国家限制；城市进入关键词，全球主题不自动加国家。失败/越权尝试只登记稳定错误码，知识库查询登记哈希，拒绝的私有查询不写入公开调用日志。Agent 自己的总结永不作为证据。

## 累计预算与覆盖

知识库预检、后续知识库工具及 Tavily 两工具共用最多 4 次尝试，失败、拒绝与缓存命中也不能绕过上限；提取页尝试累计最多 12。公开计划与 Agent 的所有模型重试计入持久检索阶段上限 3 次，同时为回答/出题与独立审核保留额度。账号每分钟和任务原始截止时间继续生效。

检索结果按资料/公开来源轮流分配，知识库与网页各最多 12 段，最终上下文最多 24000 字符。索引先给各份相关资料候选机会，长资料不能挤掉相关短资料；原文和哈希去重，向量相似度只筛候选，能否支持结论仍须独立审核。

检查点绑定原始目标、资料版本、配置指纹和联网权限；变化时拒绝复用。每个付费步骤重新核对范围、账号、取消与租约，失效范围仍可进入安全失败终态并释放旧 AI 忙碌资格。

`19-retrieval-budgets-red.xml` → `19-retrieval-budgets-green.xml`：15 passed；`19-retrieval-store-red.xml` → `19-retrieval-store-green.xml`：26 passed；`19-index-coverage-red.xml` → `19-index-coverage-green.xml` 补充真实 Chroma 跨版本及长短资料覆盖，原失败报告保留。冲突来源与回答审核矩阵在问答阶段补充。

补充真实索引重复测试发现：近期写入的小资料可能在 get() 已可见、过滤 ANN 查询暂时为空。证据保存在 `19-index-order-diagnostic.*`，没有将该失败当作通过。现在对最多 256 个向量的小范围做有界精确复核，较大不可读范围返回索引不可用，避免把暂时不可读伪称为不相关；所有结果仍回源校验。最终 `19-index-coverage-green-final.xml` 为 25 passed，包含 5 次重复覆盖及完整检索链路。

## 失败与支持性矩阵

| 情况 | 处理 | 证据 |
|---|---|---|
| 文档指令要求外传私有哨兵或越权资料 | 服务端拒绝参数，不发公网请求，安全审计不保存拒绝的私有字符串 | 18-agent / 19-repeated-context |
| 关闭联网 | 不调用公开计划或 Tavily，仍检索所选知识库 | 18-agent |
| Tavily 缺少配置/失败、私有资料充分 | 明确联网未用/失败，独立审核通过后仅依据资料回答 | 19-routing-boundaries / 22-question-history |
| 索引不可用 | 保留技术错误，不用模型猜文档 | 19-retrieval-store / 22-question-history |
| 只有公开证据而目标依赖私有文档 | 资料不足，不猜测私有事实 | 21-answering |
| 片段真实但不支持结论、虚构引用、明确矛盾 | 独立审核拒绝，有限修正后仍不足则不发布正文 | 21-answering / 22-question-history |
| 多来源冲突 | 允许分别限定出处说明；不能当唯一确定结论 | 22-question-history |

调用记录只保存受审查的公开参数、来源 ID、稳定错误码与用量；知识库检索查询以哈希登记。以上为受控供应商边界和真实存储测试，不替代后续真实模型内容评估。
