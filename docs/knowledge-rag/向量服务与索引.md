# 百炼向量服务与索引

独立 KNOWLEDGE_EMBEDDING_API_KEY / BASE_URL，只接受北京工作空间原生 `/api/v1` Host 或既有北京 DashScope Host；不复用 DeepSeek 凭据。模型固定 text-embedding-v4、1024 维、cosine，document/query 明确区分。原生路径 `/services/embeddings/text-embedding/text-embedding`，没有设置 SDK 全局地域。

每批最多 10 段，每段保守限定 UTF-8 8192 字节；字符分块之后再检查字节边界，必要时按完整字符继续拆分。字节数仅用作 Token 预留上界，不冒称实际 Token 数；服务端仍拒绝时明确失败。实际总 Token 从可信响应 usage 回填；无用量或响应丢失保留预留。当前每日 20 万上限，所有失败尝试均预留，认证/余额失败不盲目重试。瞬时网络故障、429、服务端错误最多三次并退避，总等待受原任务期限约束。

同步/异步 LangChain Embeddings 接口共用受限 HTTPX 适配。校验条数、唯一 text_index、顺序、1024 维和有限数值；异常不进入缓存或索引。成功前复核任务；取消后的已发生调用仍计量。缓存按账号、完整配置指纹、内容哈希及 document/query 隔离。同批重复文本只请求一次。MySQL JSON 浮点回读可能相差一个 ULP，测试使用 1e-12 容差，原始失败报告保留。

测试 `14-embedding-red.xml` → `14-embedding-green-final.xml`：23 passed（含额度回归）。真实 HTTP 请求结构由 HTTPX MockTransport 接收，MySQL 为隔离真实库；没有调用真实百炼。官方用法通过 Context7 的 DashScope SDK 文档、LangChain Embeddings 接口和百炼原生同步 Embedding 官方说明核对，检索日期 2026-10-18。真实端点尚待用户本地配置。

## 可重建索引与发布

API 从不开本地 Chroma。执行器同时持有目录锁和数据库租约，才允许创建 PersistentClient；每用户及完整 Embedding 配置使用独立集合，集合还保存账号/配置标记。提供嵌入向量并关闭默认 embedding_function，不下载其他模型。

SQL 持有实际正文、位置、块哈希和版本；Chroma 只保存向量及受控标记。检索限定选中资料和版本，回源后再次核验账号、活动版本及删除状态，只返回 SQL 正文。不存在的块、伪造索引正文、无关余弦结果和重复块不能成为证据。

入库每轮最多处理一个小批次，然后让出执行槽，交互与清理优先。正常让出不消费故障恢复次数。检查点对应已写向量批次；恢复验证批次存在，缺失则从账号缓存恢复。全清单的 ID、条数、维度和数值校验完成后，才在一个事务中切换活动版本、写唯一结果并标记 succeeded/100。失败重建保留旧活动版本。

`15-index-red.xml` → `15-index-green-final.xml`：12 passed（含分块）；补充真实账号集合隔离及 API 后，`16-management-green-final.xml` 共 44 passed，包含旧账号回归。`16-cleanup-green.xml` 为 12 passed，包含独立执行器驱动真实索引入库。索引测试使用真实临时 Chroma + MySQL，Embedding 网络边界受控。

## 删除、清理和运维

删除资料在事务中先标记不可用、取消导入并写独立清理 outbox；立即无法选择或检索，后台幂等删除所有对应配置向量与原始文件，并清空原文/分块。失败按稳定错误码保留 outbox 并退避重试，不恢复资料。账号注销在原账号事务中先写 outbox，再由外键清空账号关系；outbox 无用户外键，仍能删除该账号文件桶及集合。旧数据库尚未进行可选迁移时保留原注销行为。

未完成暂存版本超过 24 小时且没有有效任务时进入垃圾回收；活动版本及仍在处理的版本不会回收。没有活动版本的失败资料同时清理过期上传文件。历史问答和题目保留必要引用快照，原文删除状态在来源读取时展示；删除相应历史与注销账号按各自生命周期处理。

- 备份前关闭知识库新提交、等待当前批次结束并停止执行器；备份 MySQL、完整专用存储目录（含标记、文件与 Chroma）。先恢复 SQL 与文件，再启动执行器。
- 索引损坏时保留 SQL 和原文件；通过资料 reindex 提交新暂存版本，验证完成后切换。不要手改集合维度或把别的配置写到原集合。
- `POST /documents/{id}/reindex` 使用 Idempotency-Key，重建计入当天导入/重建次数及实际向量用量；旧版本在新版本成功前保持可用。
- `DELETE /documents/{id}` 幂等，并在关闭新功能入口时仍允许本人删除。不要在关闭开关后直接丢弃专用目录或清理队列。
- 更改存储根目录时要先停止执行器并整体迁移专用目录；服务器不会按客户端路径去猜测或删除其他目录。
- 回退先关闭新入口并保留执行器处理清理；保留 SQL 新表、原始文件和快照，旧核心继续使用。只有全部新增表为空时才允许降级 007；不得为了降级清空用户数据。
