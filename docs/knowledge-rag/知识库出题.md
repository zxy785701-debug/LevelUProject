# 知识库学习范围与关卡

POST `/quiz-preparations` 接收 goal、明确资料范围与 supplement（默认true），持久保存 prepare 任务。提交仅扣一次原学习范围准备次数，不占旧 AI 忙碌资格。处理过程检索真实资料，整理最多一层可多选主题卡；第一个候选为推荐，知识点由服务端按所选主题平衡整理。

GET `/quiz-preparations/{id}` 返回 knowledge_scope、版本、原始目标、资料版本、联网选择、主题、证据及推荐值。范围不可变且有期限；确认必须绑定 scope ID、版本和原联网选择。资料更新、删除、跨账号、修改联网权限、过期或无效主题均拒绝，要求重新准备。确认本身不创建关卡或奖励。

范围准备只使用真实证据，引用不存在或无依据的候选不得发布；资料不足返回明确业务结果。`23-scopes-red.xml` → `23-scopes-green.xml`：12 passed，包含真实索引与额度回归。

新知识库显式传递 knowledge_policy=strict，不伪造 Material 记录。每题仍生成草稿并独立审核，所有正确选项与讲解都须由实际来源支持；无依据拒绝，不能走旧一般主题的未核实降级。只对实际引用的联网来源登记 Tavily 核实信息，未使用网页不能冒充支持。旧一般主题和旧材料策略继续保持。

POST `/quizzes` 接收 scope_id、scope_version、candidate_ids、question_count（3或5）、difficulty 及原 supplement。服务端重验确认范围后保存 quiz 任务，生成稿、审核结果及最终审核通过的题目分别持久化。最终在同一事务调用原 store_quiz 的可选 Session 适配，保存原有 QuizRow/Attempt、操作结果和任务成功。旧 store_quiz 调用仍默认独立事务。

恢复已审核关卡只重新取得原操作的发布资格，不伪造一次新模型调用，不重复扣闯关次数。租约失效的旧执行者不能发布；新 fence 可以复用审核结果。任务查询会读取最新作答状态，未答题仍隐藏答案及引用。删除学习记录同时清理知识库任务的旧结果和检查点，保留旧核心的奖励账本与重闯行为。

证据：`24-knowledge-quiz-red.xml` → `24-knowledge-quiz-green.xml` 为30 passed，包含旧主题/材料策略和多选回归；`25-quiz-publication-red.xml` → `25-quiz-publication-green.xml` 为5 passed；额外租约及真实使用来源测试保留 RED；最终 `26-publication-learning-green-final.xml` 为27 passed，包含报告、重闯、错题复习、删除及旧默认行为。完整旧格式回归随后单独登记。
