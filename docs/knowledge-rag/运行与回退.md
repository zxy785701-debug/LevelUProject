## 启动与检查

在项目根目录执行：

```powershell
./scripts/start.ps1 -Target weapp
```

启动器先执行迁移和旧后端启动检查，再检查可选知识库执行器；有健康执行器时复用。退出时只停止由本次启动器创建的进程，复用的服务不会被误停。可选执行器异常不会结束原核心后端。

只检查配置或心跳（不打开 Chroma、不调用收费服务）：

```powershell
./scripts/start-knowledge.ps1 -Check
./scripts/start-knowledge.ps1 -Status
```

单独启动执行器：`./scripts/start-knowledge.ps1`。API 健康地址是 `http://127.0.0.1:8000/api/v1/health`。知识库接口需要正常微信登录；未登录返回 401 属于鉴权行为。

## 配置和限额

密钥只放 `backend/.env`。百炼使用北京同一业务空间的原生 `/api/v1`，独立 `KNOWLEDGE_EMBEDDING_API_KEY` / `KNOWLEDGE_EMBEDDING_BASE_URL`，不使用 `/compatible-mode/v1`。text-embedding-v4、1024 维、cosine 已锁定；配置指纹隔离集合，不能混写维度。

专用存储目录必须是绝对私有路径。SQL 保存权属、原文、分块、版本、任务与快照；Chroma 是可重建索引。API 不打开索引；单执行进程持有文件锁和数据库租约后才能写入。第二执行进程会明确失败，不能同时对同一目录启动多个执行器。

初始额度见 `.env.example` 和 `配置与测试.md`：单文件 20 MB、100 份资料、500 万正文字、每天 20 次导入/重建、20 次问答及 20 万 Embedding 输入 Token。语言模型继续共享原有每分钟 10 次限制；失败、重试和实际审核请求也计量。重试不重置预算、原始截止时间或已消费的关卡资格。

## 中断恢复和索引重建

正常退出先等待已执行批次结束再释放目录锁。强制中断时，等待原租约到期，重启执行器会接管持久任务，按检查点继续；不清空任务表或手工把任务改成成功。页面离开只停止轮询，真正取消使用任务取消接口。

索引损坏时保留 MySQL 和原始文件，在资料详情提交「重建索引」。新版本全量校验后才切换，失败期间旧活动版本仍保留。不要直接修改集合、删除用户目录或重置额度。

删除先在 SQL 中立即禁止资料检索，再由独立 outbox 幂等清理。失败清理会保留并退避重试。账号注销后 outbox 也不会随外键级联丢失。

## 备份与恢复顺序

1. 暂停外部新提交，等待或取消当前任务，正常停止 API 和执行器，核对没有其他索引写进程。
2. 备份 MySQL 和完整知识库存储目录，包含目录标记、原文件与 Chroma；记录版本、时间和校验值。只复制正在写入的 SQLite/Chroma 文件不能视为一致备份。
3. 恢复时先把 SQL 与完整存储目录恢复到同一备份时点，核对访问权限及根路径，再启动单执行器与 API。
4. 如只丢失索引而 SQL/原文完整，使用重建流程；不要把不同备份时点的 Chroma 当作权属或正文的事实来源。

本次已真实创建迁移前 SQL 备份并复核哈希；未在业务库执行覆盖恢复。隔离测试覆盖迁移升级/空表降级、重启接管、检查点恢复和旧版本切换。
