# 私有知识库使用说明

入口：登录后进入「我的 → 私有知识库」。旧的主题、材料、视频、复习和学习记录入口继续使用原流程。

## 添加资料

1. 点击「添加资料」，选择文件、公开网址，或从自己的已有材料复制。
2. 文件支持 PDF、Word（DOCX）、TXT、Markdown（MD / MARKDOWN），单个文件最多 20 MB。扫描 PDF 暂无 OCR；没有可提取文字时会明确提示。
3. 上传、解析、分块、向量化和校验分别显示进度。「上传完成」不等于「资料就绪」，需要等待处理成功。
4. 打开资料详情查看文件名、版本和原文片段。PDF 显示实际页码，Markdown 保留标题位置。

文件处理会使用已配置的云端向量/语言模型服务。公开网址只支持服务器可访问的公共页面；需要登录、内网页面和无法获取正文的网址会返回明确错误。

已有材料会复制为独立知识库资料，之后不依赖旧材料的临时文件。不会自动把全部旧材料转存入库。

## 提问与查看来源

1. 勾选资料，或明确选择全部就绪资料，输入本次问题。
2. 「允许联网补充」默认开启，可在提交前关闭。系统会按实际需要选择资料检索及公开搜索；开启联网并不代表每次都必须搜索。
3. 回答按段显示引用。点击引用查看对应资料、版本、页码或标题及原文片段。
4. 资料不支持的问题会提示不足；互相矛盾的来源会分别说明，不替你猜一个有效版本。索引或服务故障会显示技术错误。
5. 问答历史可以查看、删除。问答不增加经验、金币、作答记录或学习报告。

每次提问只使用这次问题和所选资料，没有默认携带之前对话。「按这个问题出题」会带入原始问题、原资料范围与联网选择，再次确认后出题；AI 回答本身不作为证据。若原资料已更新或删除，需要重新选择资料。

## 生成关卡

1. 选择资料，填写学习目标，确认联网选择，点击准备范围。
2. 在一层主题列表勾选一个或多个主题，默认选中推荐项；可先查看证据和范围。
3. 选择 3 / 5 题与难度并生成。目标、资料版本或联网权限改变后，需要重新准备范围。
4. 关卡就绪后进入原有答题页。提交答案后才显示判分、讲解和来源，未答题时不会提前显示答案。
5. 答完最后一题生成报告。历史、重闯和错题复习继续使用原有规则。

资料支撑与答题正确率分别显示；题目答对不会把「仅材料支撑」升级成「已联网核实」。

## 离开、恢复和失败处理

- 返回首页或切后台会暂停页面请求，服务器任务继续处理；回来可恢复同一个任务，进度不会倒退。
- 需要真正停止时使用「取消任务」。失败或取消后的重试沿用原始预算与截止时间，超时后需要重新提交。
- 网络断开后先恢复原提交；客户端会查询原请求，避免重复上传、重复生成。
- 账号切换后，资料、草稿和任务记录按账号隔离；不会继续显示上一账号内容。
- 文件选择器返回后先核对所选文件，再提交上传；打开系统选择器造成的暂时切后台不会自动丢弃选择。
- 若提示「微信开发者工具无法打开文件窗口」，先完全退出并重新打开工具；仍失败时更新工具。2026-10-19 用户已确认重启后窗口恢复；本次问题发生在工具原生文件选择阶段，尚未进入上传请求。

## 删除和重建

删除资料后立即不能再检索或用于新出题，后台继续清理文件与向量。已有问答、题目引用保留必要快照，并显示原资料已删除；删除问答历史与删除资料是两个独立操作。

重建成功前继续使用旧活动版本；失败不会用半成品替换旧版本。重建同样受导入次数和向量用量限制。
