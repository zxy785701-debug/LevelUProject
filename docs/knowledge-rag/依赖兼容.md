# 连续执行任务的模型传输

2026-10-18 真实 Windows 联调发现默认异步客户端缓存可能跨越任务的 `asyncio.run` 生命周期。新增任务现在在本次事件循环中创建并关闭独立 HTTPX 异步客户端，通过上下文传给范围整理、Agent、生成和独立审核；原 API 默认连接行为不变。先用5项失败测试复现连续、并发及异常清理，再修复通过，见43-model-transport-red/green。

Context7 使用 `/websites/reference_langchain` 核对 `ChatOpenAI.http_async_client`：该参数接受 `httpx.AsyncClient`，仅影响异步调用，且不会进入序列化输出。当前已安装的 langchain-openai 同样暴露此参数。参考：[LangChain 官方 API](https://reference.langchain.com/python/langchain-openai/chat_models/base/BaseChatOpenAI/http_async_client)。
