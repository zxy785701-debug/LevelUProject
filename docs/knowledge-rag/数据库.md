# 知识库增量数据库

迁移 `007_personal_knowledge` 接续 `006_retrieval_audit`。新增独立的 documents、revisions、chunks、jobs、checkpoints、scopes、questions、cleanup_outbox、usage、worker_leases、embedding_cache、published_results 表，均带 knowledge_ 前缀。旧表和旧题库 JSON 不改写，旧材料不自动导入。

资料按用户外键隔离，版本号在文档内唯一，分块位置在版本内唯一，任务幂等键在用户/任务类型内区分大小写且唯一。发布操作结果以 operation_id 唯一。正文、版本与分块是可重建索引的事实来源；Chroma 不承担权限来源。

cleanup_outbox 的 user_id 有意不使用用户外键，使删除账号后外部文件/向量清理指令仍可存活。usage 保存身份摘要与上海自然日，独立于用户删除，防止注销重注册刷新当天额度。清理任务载荷和身份摘要不下发前端。

迁移定义在修订文件中冻结，不引用可变 ORM 模型创建历史结构。迁移入口登记新模型供元数据检查使用，不加载向量库。新迁移只允许所有知识库表均无数据时降级；有资料、用量、任务或快照时拒绝破坏性降级，使用功能开关停止新提交并保留可读快照。
