# 知识库单轮问答

POST `/api/v1/knowledge/questions`：`{question,document_ids?,all_ready?,supplement?}`。question 为 1–6000 个去除首尾空白的字符；document_ids 与 all_ready=true 二选一，不接受隐式空范围、重复 ID、账号或 history 字段。supplement 省略时明确为 true；关闭后不调用公开检索计划或 Tavily。

鉴权、范围/活动版本和独立日额度验证成功后返回 knowledge_job / question / queued；队列不占旧 AI 忙碌资格。首次提交即预留一天的一次问答，当前上限20；模型调用识别这份预留，恢复及重试不再扣问答次数。旧模型每分钟限制继续按真实请求计量，问答不新增作答、闯关次数、经验或金币。

同一 Idempotency-Key 与参数复用任务，修改问题/范围/联网权限返回409；跨账号资料按404拒绝。后台载荷只包含本次原始问题、服务端资料版本快照和联网权限，没有隐式历史上下文。

## 回答、历史与后续出题

回答先生成结构化段落，再由独立无工具审核逐段检查直接支持、事实矛盾、歧义及是否回应原目标。每段必须绑定真实来源；最多一次修正，仍未通过则返回资料不足，不发布未审核正文。目标依赖私有资料时，只有公开网页不能替代；索引/向量服务故障保留技术错误。来源冲突可以按出处分别说明，不能强行统一成唯一结论。

问答草稿和审核分开保存检查点；最终 Question、根操作结果及 Job succeeded 在同一事务发布。GET `/questions` 返回分页摘要；GET `/questions/{id}` 返回回答、引用、资料版本及删除状态；DELETE 同一路径幂等删除历史，并清除对应草稿/检索检查点与任务载荷中的问题内容。库内原资料按自己的生命周期保留。问答不建立 Attempt、Reward、错题或学习报告。

GET `/questions/{id}/quiz-context` 只返回原始问题、原始资料版本与联网选择，并明确 requires_confirmation=true；从这里去准备范围，再确认主题后出题。AI 回答永不成为新证据。资料已更新或删除时返回409，要求用户重新选择资料，不能默默套用新版。
