# 资料正文与可定位分块

支持文字 PDF、DOCX、UTF-8/GB18030 TXT 与 Markdown、单个公开网页；不支持 OCR、旧 DOC、加密 PDF。沿用旧文件 20 MB、全文 10 万字符、PDF 200 页、DOCX 解压 50 MB 与条目数量限制，新增格式先验证签名和文本内容。Markdown 中代码、表格、HTML 只保留为文字，不执行或抓取引用资源。

PDF 保留实际页码，空白页过滤不会把第三页误标为第二页。Word 保留段落/表格提取顺序，使用提取块位置而非虚构页码。规范化正文持久保存，所有 start_index/end_index 都指向这个正文的字符位置，不代表 PDF 二进制偏移。文本换行统一为 LF，块同时保存行范围、标题层级、哈希和策略版本。

MarkdownHeaderTextSplitter(strip_headers=False) 用于标题元数据，另外映射原始行边界以避免其空白规范化改变代码与定位。代码围栏中的 # 不产生章节。RecursiveCharacterTextSplitter 在同一页/章节内按中文标点等分隔；默认目标 1000 字符、重叠 150 字符，不跨页/章节。这里是字符设置，不能据此声称 Token 等量，向量请求另做上界校验。

网页只复用官方 Tavily Extract 的实际 raw_content，保留请求 URL、真实抓取时间、原始字符数和截断标志。摘要、私有地址及未请求的重定向内容不能入库。网页/已有材料正文复制持久化，不能靠临时材料引用维持资料有效。

解析结果与 parsed 检查点、分块/清单与 split 检查点分别在原子事务保存。暂存版本 ID 由根操作确定，恢复先读检查点；不再读取已完成解析的上传文件，不创建重复版本或分块。最终活动版本切换由索引发布阶段负责。解析落库前复核账号、取消、租约、删除状态与账号总正文额度，失败不会触发 Embedding。
