## 微信 WXSS 编译兼容修复（2026-10-12）

开发工具报告 `app.wxss(1:277): unexpected token *`。使用本机开发工具附带的 `wcsc.exe` 复现后，还发现原型底部按钮的 `:is(...)` 选择器不兼容。

- 使用 Taro 官方的 `sass.data` 注入编译平台变量，小程序的全局和 Tab 子元素通配选择器改为明确的原生元素选择器；H5 保留原通配样式。
- 将 `:is(...)` 改为 Sass 嵌套生成的普通选择器列表，保留按钮颜色、字号、间距与交互状态。
- 重新生成 `frontend/dist/`，并同步工程当前 AppID。增加 `npm run check:wxss -- "本机 wcsc.exe 的绝对路径"`，直接检验全部 WXSS 构建文件。结果见 `wxss-check.json`，构建日志见 `weapp-build-wxss-fix.txt`。
- 本轮微信样式编译器检查、TypeScript 检查、H5 构建均通过；5 题闭环与 320px 长文本两项浏览器回归通过（`e2e-wxss-fix.txt`）。交付 ZIP 已同步更新，微信包体 0.970 MiB，密钥扫描通过。

配置依据：[Taro sass.data](https://docs.taro.zone/docs/config-detail#sassdata)、[Taro 跨平台环境变量](https://docs.taro.zone/docs/envs/)。WXSS 检查证明样式语法可被微信编译器接受，完整页面视觉仍按上面的补验步骤检查。
