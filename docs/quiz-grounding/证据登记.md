# 证据登记与完整性

只有官方工具实际返回且具有可用正文、公开网址的结果可以登记。Agent 的结论和供应商自动答案不能添加来源。片段按网址、内容类型及文字摘要生成稳定 ID，按 4000 字符分段，重复内容复用 ID。

- 搜索摘要标记 `snippet`；请求全文但实际只有摘要时仍为摘要。
- 实际取得正文标记 `full_extract`，定向读取标记 `focused_extract`。这表示返回内容的获取方式，不保证所有动态网页内容都已取得。
- 记录获取时间、供应商返回的发布时间（未知则空）、来源标题、原网址、内容哈希及原正文字符数。发布时间不从获取时间推算。
- `truncated` 表示 SDK 返回后保留正文时被限额截断；`context_truncated` 表示本次传给模型的片段进一步截断。原快照不因本次模型上下文裁剪而改写。
- 工具保留正文按默认 2 MB 预算在各结果间分配；这是 SDK 已解析之后的保留限制，不宣称是网络传输或 JSON 解析内存上限。默认累计入模文字预算 24000 字符，所选知识点轮流分配，不能让一篇长文挤掉其他知识点；预算用尽不添加虚构内容。
- 登记资料不等于审核通过。摘要可以支持其明确写出的事实，未写出的结论不能因来源真实而得到支持标记；逐题语义审核在任务 4.3 接入。

调用 Extract 前及展示来源前使用现有公开网址校验，拒绝内网、混合公网/私网 DNS、凭证和非 HTTP(S) 地址。服务端已有直接读取路径仍使用固定已验证 IP 与每次跳转校验。官方 Extract 在远端执行抓取；本服务不替其宣称掌握内部跳转过程，只登记与请求网址关联的实际内容。

传给模型的资料采用独立 JSON 数据段，系统说明明确禁止网络正文更改工具、账号、预算、学习范围和补充开关；实际工具权限与额度仍由程序控制，正文中的指令没有配置权限。
