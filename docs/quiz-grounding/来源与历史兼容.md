# 来源快照与历史兼容

Quiz 保存完整用户确认范围、逐题核实状态及真实来源片段。来源是随题库复制的快照，题库和学习记录不依赖短期准备表存活；准备 24 小时清理不删除已经生成的来源。

快照区分摘要、完整提取模式与定向片段，记录原文/获取时间、未知日期、标题、网址、获取截断和入模截断。界面只能据真实字段描述完整性，不能把有正文或真实 URL 等同于完整、已核实。

Session 的所有返回路径使用同一投影：未答题隐藏答案、讲解、逐题 source_ids 和审核理由；来源片段只显示已答题实际引用的集合。操作查询会读取当前 Session 再投影，不以首次操作缓存绕开。用户确认页中已主动预览的学习材料按原流程显示。

旧题库缺少新增字段仍可读取，缺少核实记录保持未知，不能默认 source_backed。旧材料来源的页码与字幕起止时间保留。评分、首次答题奖励及统计依据继续使用服务端存储的完整题库。

重闯复制原题库快照，不依赖短期准备。组合错题为每个“原题库 + 原片段 ID”生成独立来源 ID，同时保留 original_id、original_quiz_id；每题 origin 保存原题/题库、标题和确认范围。不同题库的 s1 不再互相覆盖，同一原片段可复用，逐题核实状态原样保留。混合旧题库的未知状态不会被升级；复习奖励继续按现有口径不重复发放。

学习复盘保存程序生成的 verification、确认范围和来源；周期报告快照版本 2 增加各原题库 provenance，导出文字报告显示真实状态。模型只分析答题表现，不能把未核实或旧题库未知状态写成已联网核实；这种输出会被拒绝。周期报告模型只接收来源元数据，不发送不必要的来源正文，完整快照仍供本人查看。数值统计、首次学习/复习口径和掌握度规则保持原样。
