# 范围、草稿与独立审核

范围整理 `scope-v1`、检索策略 `retrieval-policy-v2`、有依据草稿 `grounded-draft-v2`、无依据主题降级 `unverified-draft-v2`、独立审核 `evidence-review-v2` 均为版本化模板，使用 ChatPromptTemplate 和现有 JSON 网关。没有针对用户示例主题的生产分支。历史来源快照保留原审核版本，新题库及逐题状态显式记录本次审核版本。

生成输入保存完整原始意图及已选领域/方向/知识点。范围准备中的新鲜片段按确认方向复用，默认 30 分钟后重新检索；材料补充只围绕所选知识点。摘要也可作为证据，但不能据其推断未写出的内容。3 题配比为单选/多选/判断各一；5 题为三单选、一多选、一判断。草稿输出 ready 或 insufficient_knowledge，后者明确失败并提示缩小范围/补充资料。

材料附带学习说明时，说明同时成为范围快照的 `input_text` 与 `focus`，自动标题和摘要知识点不能将其扩大为整份文档的一般背景。检索消息先明确原始任务和确认方向，再附完整范围；草稿和审核均要求实质回应比较、机制或应用等原要求。实际网页对比案例暴露了泛化摘要压过说明的问题，修复及历次失败/偏题结果保留在真实评测记录中；没有把安装题替代对比题后当作验收成功。

网络和材料正文以 JSON 数据传入，不能更改系统约束。现有网关检查空返回、JSON 解析、内容过滤、截断和 Pydantic 跨字段规则，每次实际重试仍计调用预算。

## 审核规则

独立无工具请求核对每题题干、正确选项及讲解，返回 supported / unsupported / contradicted / ambiguous / off_scope，并检查学习方向实质覆盖。

- supported 还须有本次真实片段 ID；模型自行给出的 grounding 不采信。
- unsupported 没有确定矛盾时，主题题目可以删除错误引用、标记未核实；材料题目需要材料直接支持，不能换成无关已有知识。
- contradicted、ambiguous、off_scope 或方向未覆盖必须修正再审核；不能仅改标签发布。只有预算能容纳完整“修正 + 审核”时才执行。
- 混合题库中任何未核实题都会使整体标为未核实，逐题保留真实状态。部分来源存在不意味着所有题已核实。

真实来源但不支持结论、伪造 ID、混合核实、已知矛盾、争议、偏题、方向覆盖及修正预算都有可控审核响应测试。这验证程序对审核结果的处理；模型语义准确率仍需真实资料逐题人工验收。
