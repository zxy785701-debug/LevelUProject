# 前端学习流程与恢复

2026-10-14；维护入口 `frontend/`。当前浏览器证据来自本机 H5、可控接口响应，不能代替真实 Tavily 效果验收。

## 输入和确认（6.2）

- 首页关键词进入准备，展示后台取得的领域、方向、知识点和引用片段。多领域不自动替用户选择；单领域、单方向可预选，但始终需要点击“确认范围，生成关卡”。
- 一个公开网页网址连同附加说明进入网页材料页，读指定网页后确认材料范围。默认关闭联网补充，不因识别网址搜索外链。
- 纯网址读取失败显示补充正文或明确主题提示；后台认定说明包含独立学习主题时，可移交“未联网核实”的范围供确认，没有虚构网页预览。
- 返回修改主题保留原输入。320px 页面实测无水平溢出。

验证：`npm run typecheck`；`npm run test:e2e:grounding` 的范围选择、网页分流、未核实确认、网址读取失败用例通过。截图在 `screenshots/scope-confirmation.png` 和 `screenshots/scope-unverified-320.png`。

## 后台阶段和恢复（6.3）

阶段文字取自服务端 searching / extracting / waiting_rate_limit / generating / reviewing 等状态；等待时间来自服务端，页面不模拟进度。准备取消会请求服务端释放原准备；离开已提交出题仅停止本页查询，出题继续。

准备和出题恢复信息按账号保存，出题包含原幂等键与不可变选择。首页“恢复出题进度”使用原键提交并查询，结果不会重复生成。每个请求最长15秒，准备查询上限255秒，出题查询上限330秒；准备至多120次；生成至多330次，出题和审核阶段每秒查询，其余阶段有限退避和连续3次网络重试。离开页面、账号切换或卸载使旧回包失效。

材料解析查询同样有截止时间和单独取消范围。材料出题明确提交 `execution=background`，与主题使用同一后台查询和首页恢复路径。

验证：浏览器退出并刷新后恢复同一键、真实限流阶段、准备取消通过；单元测试核对 HTTP 超时、有限退避、请求隔离、账号 epoch 和旧回包拒绝。

## 依据展示（6.4）

参考资料展示服务端实际片段、来源标题和链接、获取/发布日期，未知日期明确显示“未知日期”。摘要、正文、定向片段、材料页码与字幕时间分别标识；获取截断、部分可读和入模截断分别显示。

准备状态仅说明取得资料。题目与报告使用服务端核实状态；历史缺少字段显示“未记录核实状态”，不补标为联网成功。逐题讲解只展示该题引用，组合错题保留原主题、原范围；周期报告按原学习记录展示状态与可展开来源。
