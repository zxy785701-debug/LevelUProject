# 可审阅的查询策略样例

策略版本 `retrieval-policy-v1`，当前日期在运行时注入。以下为离线验证的合法策略示例，不是对真实模型理解能力或真实 Tavily 覆盖率的验收；真实矩阵按任务 7.3 执行。

| 场景 | 查询与参数选择 | 停止或补充条件 |
| --- | --- | --- |
| 稳定基础知识 | 原始术语 + 官方文档；summary/basic/3 条；无 country | 摘要直接写出所需事实即可使用；缺少上下文再 Extract |
| 新的复杂工程概念 | 原术语、架构/实践/发布记录；full/advanced/5–8 条 | 已有正文不重复取；不同领域作为候选供确认 |
| 中文学习国际技术 | 中文检索缺口后补英文原文查询；无 country | 回答仍可中文，保留英文来源和原始术语 |
| 中国流行文化与热梗 | 主题 + 梗/名场面/语境关键词；按时效调整时间窗口 | 核实实际语境和归属；资料不足不能只用节目名冒充热梗 |
| 法国文化资料 | 法语查询，general + country=france | country 仅影响排序，仍检查来源讨论的是法国 |
| 美国佐治亚州雅典 | Athens Georgia United States city history，general + country=united states | 不以希腊雅典资料替代；同名未消歧时保留候选 |
| 巴黎近期新闻 | Paris France actualités，news + week，省略 country | news 不支持 country；城市/国家保留在关键词内，失败不静默删掉 |
| 用户给定网页 | Extract full，basic 起步；复杂页面可 advanced | 失败提示未读到；无额外补充授权不搜索或跟随文中外链 |

国家字段白名单和不适用组合在程序层拒绝。城市无法使用供应商原生筛选，必须检查查询和结果实际地域；模型策略明确禁止默默放宽地域，真实遵循程度需要在真实评测中核对。没有编写示例主题专属的生产代码。
