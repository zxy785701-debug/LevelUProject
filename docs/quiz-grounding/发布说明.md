# 联网出题发布与恢复

本轮代码、回归和真实20例已完成，用户确认微信流程成功及60题核对结果正确，人工确认粒度见 [验收记录](验收记录.md)。此文件不是正式部署成功记录。

## 配套升级

1. 备份业务库，停止新的生成提交；先在独立测试环境验证增量迁移。禁止对业务库执行pytest或测试库重建脚本。
2. 安装锁定的 `backend/requirements.lock`。使用官方 `langchain-tavily==0.2.18`；保留现有 LangChain 和 DeepSeek 模型配置。双工具、异步行为及模型工具调用记录见 [实施记录](实施记录.md) 和 [工具映射](Tavily工具映射.md)。
3. 在后端配置 Tavily 凭证及预算，检查脱敏配置，运行原有启动迁移入口，确认 Alembic 为 `006_retrieval_audit`。MySQL DDL中断须核对实际列/版本，不删除表重试。细节见 [迁移说明](数据库迁移.md)。
4. 同步部署本轮前后端，构建H5/微信并执行模块启动及正式WXSS检查。微信真机配置HTTPS API和合法域名，前后端AppID保持一致。
5. 核对 [验收记录](验收记录.md) 和目标部署环境后决定上线。本轮人工验收已按用户确认登记；当前未执行正式部署。本机运行库因用户联调发现缺失字段，已备份并升级至006，详情见验收记录。

## 行为与兼容

主题准备先联网获取资料，始终由用户确认领域/方向/知识点；默认准备每天20次，不扣关卡。正式出题首次实际模型调用扣一次关卡，后台独立审核，按原键恢复。网址和附加说明进入网页材料，指定页读取与全文/定向提取区分，补充仍是用户选项。

每阶段模型总预算5/7次，检索规划最多3次、工具4次、实际页面尝试12次；单工具20秒，准备240秒、后台生成300秒。账号每分钟10次（2026-10-14 经用户确认提高）、同时1项操作，等待在同一后台操作内发生；原模型请求的内部重试也计数。

旧文本直接出题返回409 `SCOPE_CONFIRMATION_REQUIRED`；客户端必须配套更新。旧材料请求不指定 `execution` 时保留同步 Session 返回及90秒边界，新前端显式 `execution=background`，只把最终查询结果当Session。账号、答题、奖励、复盘和历史路径保留。

新题库保存确认范围、逐题核实状态和真实来源快照。旧JSON字段可缺省，不补标“有来源支持”；错题组合保留原题库命名空间与原主题。来源随题库保留，不依赖准备记录存活。报告的统计不改口径，未核实内容不会因复盘变成已核实。

## 暂停与恢复

设置 `QUIZ_GROUNDING_ENABLED=false` 并重新启动后端，可暂停新主题准备与新后台出题。已有操作结果按原键恢复、已开始的答题、报告、历史重闯继续；旧材料同步接口仍可用。开关不会取消已提交操作。恢复配置为true并重新启动即可重新开放。

开关测试已验证暂停时已有操作、答题、报告和重闯可用。回退应用须使用能读取本轮来源快照的版本，保留增量表/列，不执行破坏性downgrade、不重写旧题库。不能直接回滚到会拒绝新增JSON字段的旧版模型。

任务使用单进程 BackgroundTasks + 数据库租约，不是持久队列；进程重启不会自动恢复中断的执行。查询返回明确终态后使用新的操作键重试，查询断网则继续原键。准备24小时失效，证据30分钟后需刷新；到期不能新建题库，但已成功操作和题库来源快照可继续读取。

联网不可用/证据不足可在同一领域自动回退并标注“未联网核实”，不代表内容已经验证。纯网址读取失败不会猜正文；明确独立主题说明才可进入未核实范围确认。模型配置、额度和账号错误不会走知识降级旁路；不自动换供应商。
