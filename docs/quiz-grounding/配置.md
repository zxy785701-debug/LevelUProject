# 联网出题配置

配置仅位于后端 `backend/.env`，样例见 `backend/.env.example`。本轮不会改写现有凭证。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| TAVILY_API_KEY | 空 | 官方 Search/Extract 凭证；空时允许主题未核实路径，不报启动错误 |
| QUIZ_GROUNDING_ENABLED | true | 新主题准备与后台生成开关；关闭用于暂停新功能，历史读取继续可用 |
| TOPIC_PREPARE_DAILY_LIMIT | 20 | 每账号每天新主题准备次数 |
| TOPIC_PREPARE_TIMEOUT_SECONDS | 240 | 准备整体期限，包含等待及重试 |
| GROUNDED_GENERATION_TIMEOUT_SECONDS | 300 | 后台生成整体期限；旧同步材料仍受 90 秒限制 |
| PREPARE_MODEL_CALL_LIMIT / GENERATION_MODEL_CALL_LIMIT | 5 / 7 | 全阶段实际模型请求上限，包括规划、重试、审核 |
| RETRIEVAL_MODEL_CALL_LIMIT / RETRIEVAL_TOOL_CALL_LIMIT | 3 / 4 | 阶段内 Agent 模型请求与双工具尝试上限 |
| SEARCH_MAX_RESULTS | 10 | AI 动态条数的服务端上限，允许 1–10 |
| EXTRACT_MAX_URLS_PER_CALL / RETRIEVAL_MAX_PAGE_ATTEMPTS | 3 / 12 | 每次提取页面数及阶段页面尝试总量 |
| TAVILY_TIMEOUT_SECONDS | 20 | 单个工具调用期限，不能超过阶段期限 |
| TOOL_RESULT_MAX_BYTES / EVIDENCE_MAX_CHARS | 2097152 / 24000 | 应用层保留体积与累计入模证据字符预算 |
| TOPIC_PREPARATION_TTL_HOURS / EVIDENCE_REUSE_SECONDS | 24 / 1800 | 准备有效期与新生成证据复用时间 |

准备模型预算至少比检索规划预算多一次，生成至少多两次，以保留范围整理、出题及独立审核。参数可调，但不得取消已有每分钟实际模型调用限制。减少某个上限不会要求每次把其他预算用满。

模型可调参数由严格 SearchParameters/ExtractParameters 白名单限制，不能提供凭证、端点或任意额外字段。密钥以 SecretStr 保存；配置异常隐藏原始输入，日志不输出配置全文或凭证。

配置本身允许没有 Tavily 凭证启动；端到端自动降级在任务 4.4 验证。只有网址且正文不可读时仍提示补充学习主题/正文。
