# 主题准备接口与恢复

全部接口需要现有登录凭证，使用统一 `{code, message, data}` 包装。

| 接口 | 行为 |
| --- | --- |
| POST `/api/v1/quiz/preparations` | `{text}` + Idempotency-Key；立即返回准备记录，后台运行。关键词默认联网，失败按未核实范围整理。 |
| GET `/api/v1/quiz/preparations/{id}` | 返回本人状态、阶段、版本、有效期、等待秒数、范围与真实证据。 |
| POST `/api/v1/quiz/preparations/{id}/cancel` | 幂等取消 running；ready/failed 等终态不被取消或迟到结果改写。 |

POST 识别到单个网址时返回 `kind=material_entry`、url、learning_instruction，客户端转既有 `/materials/web`，此时未创建主题准备、不扣准备额度。多网址返回 `MULTIPLE_URLS_NOT_SUPPORTED`。两种数据结构已列入 OpenAPI。

关键词准备 240 秒期限、24 小时有效期。同键同输入恢复原记录，不重新执行；同键不同输入报 `IDEMPOTENCY_CONFLICT`。跨账号查询/取消统一 `NOT_FOUND`。重启不宣称继续执行遗失的任务，到期记录 `OPERATION_EXPIRED`，新尝试使用新键。清理过期准备后仍保留原操作键墓碑，防止同键再次扣费。

网页读取失败时：只有网址不调用模型猜页面；说明依赖页面内容则提示 `LEARNING_TOPIC_REQUIRED`。说明有独立明确主题时，使用无工具 JSON 整理未核实范围，材料任务返回 `stage=scope_confirmation` 和 `preparation_id`，`material_id` 为空。该分支复用既有材料操作和解析额度，不扣主题准备额度；失败页面不在来源列表。新增 `005_material_scope_handoff` 仅增加可空关联字段，准备清理会清空关联。

常见错误：`TOPIC_PREPARE_DAILY_LIMIT`（准备日额度）、`AI_BUSY`（账号仍有操作）、`AI_RATE_LIMIT`（期限不足以等待分钟额度）、`MODEL_BUDGET_EXHAUSTED`、`OPERATION_CANCELLED`、`OPERATION_EXPIRED`、`PREPARATION_EXPIRED`（原准备已清理）、`GROUNDING_DISABLED`、模型配置/认证/工具调用错误。模型与账号错误不走知识降级。

等待分钟额度时沿用同一操作，短间隔检查取消/注销；完成时准备内容与操作终态同一事务提交，人工确认期间账号租约释放。正式出题及其恢复接口在后续任务接入。

后台 waiting_rate_limit 返回真实 retry_after_seconds，等待期间保留操作租约，每次恢复仍检查期限和账号；不会新建操作、重跑工具或再次扣关卡。若期限不足等待及必要模型调用，明确失败。旧同步材料请求遇分钟限流直接返回可重试错误，并始终在 90 秒以内结算。

BackgroundTasks 无跨进程续跑承诺，遗失任务在租约/阶段期限到达后变成 OPERATION_EXPIRED；同键恢复该失败，不重新调度，新尝试用新键。已成功生成先恢复原 Session，不因准备过期或被清理而拒绝。返回首页只是离开正式生成页面，不等于撤销已发起的服务调用。

## 正式生成

POST `/api/v1/quiz/generate` 提交 preparation_id、scope_version、candidate_id、focus_id、scope_point_ids 及题量/难度，返回 `kind=generation_operation`、key、状态、阶段、等待秒数和期限。GET `/api/v1/operations/{key}` 成功时 result 为 Session；恢复优先检查原操作，准备清理后仍能取得原成功结果。

旧纯 text 请求返回 `SCOPE_CONFIRMATION_REQUIRED`（409），不扣出题次数。材料只有显式 `execution=background` 才返回操作，省略或 sync 继续返回 Session。OpenAPI 明确列出两个成功数据结构。

版本变化返回 `SCOPE_VERSION_MISMATCH`，伪造方向/知识点返回 `INVALID_SCOPE_SELECTION`，其他账号准备返回 404，准备过期返回 409；均在模型调用及出题计数前拒绝。幂等摘要包含来源模式、全部范围选择、题量、难度、补充和执行方式；修改设置必须使用新键。
