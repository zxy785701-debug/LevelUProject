# 答题体验改进（2026-10-14）

## 本次行为

- 单选、判断点选即提交本题，服务端确认后显示答案、解析与来源；确认后锁定。多选允许反复勾选，点击“确认本题”判分。这一题型差异已经用户确认。
- 每题分别保存，失败只重试本题。任意顺序答完全部题目后自动打开报告，不再经过通关页或额外的报告按钮。
- 报告立即展示成绩、用时、知识点掌握及所有题目的答案解析；学习总结异步补充，失败保留成绩并提供重试。错题复习展示本轮统计和解析，不重复奖励。
- 报告、旧通关页的返回按钮，以及报告的“返回首页”，均清空旧导航栈回到首页。迟到的总结响应不把用户带回报告。
- 历史记录每条都有删除入口及二次确认。删除本轮答题、报告和关联错题；清理该轮缓存的生成结果，避免旧操作恢复已删除记录。保留其他轮次、已获得经验金币及奖励流水。正在生成报告时拒绝删除，其他账号无法删除此记录。
- 主题准备、主题出题和材料出题使用蓝色进度条。进度映射实际阶段，不显示虚假的剩余秒数或完成率；限流时保留上个阶段位置。

## 速度调整

- 用户已确认 `AI_MINUTE_LIMIT` 从 3 调整为 10，默认值、示例配置和本机配置均同步。每日新关卡额度、单任务并发、准备/生成预算、独立审核不变。
- 模型上下文省略空值字段及 JSON 冗余空格，正文、引用 ID、非空来源元数据和截断标记完整保留。此前真实案例的引用片段离线序列化比较减少约 4.1% 字符；该比例不是耗时降低比例。
- 正在出题和审核时每秒查询结果，替代原来最长 5 秒的查询间隔。网络错误仍退避，限流仍遵守服务端等待时间，生成查询总期限仍有上限。
- 不承诺固定生成秒数；资料读取、模型响应、重试和审核修正仍影响耗时。
- 真实联网抽测 `Harness Engineering`：资料准备 52.761 秒（含范围整理的一次模型重试）；确认范围后 3 题草稿与独立审核共 10.816 秒，生成成功。准备共 5 次模型调用、4 次工具调用；出题共 2 次模型调用，复用已有资料。该案例验证链路与耗时，不作为新的人工内容验收；范围由测试操作方选择，人工审核字段保持未填，测试账号已清理。记录见 `live-runs/quiz-flow-speed-20261014/harness-2.json`。
