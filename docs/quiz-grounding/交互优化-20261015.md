# 学习范围与答题交互优化

本次按用户 2026-10-15 的确认调整，取代之前“单选/判断点选即提交”和“逐级选择领域、方向、知识点”的交互。

- 当前准备或出题页面的进度只增加，阶段回到规划、读取或限流等待时保持已达到的最高进度。
- 学习范围改为一层主题复选卡片，默认选中相关性排序第一的推荐主题，允许追加或取消主题；全部取消时禁止提交。仍须用户点击确认才能出题。
- 请求提交 `candidate_ids`，后端验证归属和版本，并在原有 12 个知识点预算内，均衡整理各主题、各方向的知识点。各主题内相同的局部知识点 ID 不再冲突。
- 题库快照保留全部已选主题、各自的知识点 ID 和真实来源。独立审核要求每个主题至少覆盖一个知识点；不足时修正或报错，不默默舍弃某个主题。
- 保留旧单主题请求和恢复键的兼容性，多选主题的勾选顺序不改变同一提交的含义。
- 单选、判断、多选统一在点击“确认本题”后判分；确认前可以修改。最后一题确认后仍自动打开报告。

验证：60 项后端测试、38 项前端单元测试、9 项范围流程浏览器测试、7 项账号/答题浏览器测试通过。类型检查、H5 构建、微信开发构建、微信官方 WXSS 编译与启动模块检查通过。最终卡片排版在正常宽度和 320px 小屏另行复测。

测试使用隔离数据库和模拟模型，没有重新消耗真实模型出题额度。本次未执行微信真机验收。
