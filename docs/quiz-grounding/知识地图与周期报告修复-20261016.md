# 知识地图与周期报告修复

日期：2026-10-16

## 用户确认的行为

- 所有已学主题放入同一张可拖动、缩放的地图，取消顶部主题列表。
- 支持按主题或知识点搜索定位，选中主题后展开知识点。
- 主题增加时保持画布大小，避免页面随主题数量不断变长。
- 修复周期报告 `MODEL_INVALID_OUTPUT`，失败后能够直接重试。

## 知识地图

`KnowledgeAtlas.tsx` 使用同一张固定高度画布绘制全部主题的布局。连线表示主题属于“我的知识”，不推断主题之间的前置或因果关系。布局按主题 ID 排序并分布在同心环上，避免节点重叠。

支持拖动、双指缩放、缩放按钮、回到中心、上个/下个主题。搜索主题名称和知识点名称，每页最多六条结果；主题详情也每页最多六个知识点，保留原来的记录查看和复习入口。主题超过一百个时仅渲染当前视野附近的节点及连线，全部主题仍能通过搜索或逐个浏览定位。

使用 Taro 官方 `View` 触摸事件与 `catchMove`，防止拖动画布时带动外层页面滚动。画布采用左上角坐标和统一缩放，窗口尺寸变化保留当前定位和比例。连线由视图绘制，不生成图片或向 Image 传递 base64。

## 周期报告

### 发现与边界

原操作 `fe58bee4-5d28-4127-9b4f-4c4a62ca27ab` 的服务日志包含语义校验失败、`summary` 字段校验失败；相邻操作还出现了 `analysis` / `action` 字段混用。旧日志没有保存语义错误的具体位置，不能断言该次操作最后命中了哪一项规则。

回归测试确认旧实现存在两类可复现问题：要求模型复制较长的知识点 ID 容易出现无效引用；核实声明正则会误拒“已经掌握验证模型”“已了解验证字段”“答对不代表知识已核实”等正常表述。

### 修复

- 给模型使用报告内部的 `p1` 等短引用，校验后还原真实知识点 ID，再保存或导出。未知引用继续拒绝，还原重复执行也保持结果一致。
- 仅发送报告需要的学习统计、知识点表现和核实状态；排除材料正文、来源网址、学习指令、作答 ID 和错题 ID。存储快照及来源记录保持完整。
- 明确要求 summary 为一至三条字符串数组，并区分 findings 的 analysis 与 suggestions 的 action。
- 核实声明校验只检查文本值，识别正常学习动词与否定表述，继续拒绝把未知/未核实知识升级为已核实。
- 前端分开保存“读取学习记录失败”和“生成报告失败”。生成失败不会再禁用重试按钮；刷新失败报告状态，确定失败后换用新的请求键。网络中断和仍在运行的操作保留原请求键。
- 保留原来的数字约束、生成次数限制和账号权限检查，没有重置真实用户的报告次数。
