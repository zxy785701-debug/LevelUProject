## 微信编译问题的结论

只读检查开发工具日志找到：`app.json: 在项目根目录未找到 app.json`。工程源码根目录的 `project.config.json` 缺少 `miniprogramRoot`，导致工具没有寻找 `dist/app.json`。已恢复配置、开启 ES6 编译并重新构建，新增配置测试防止再次遗漏。并未在源码根目录另建一份错误的 `app.json`。

官方自动化启动接口仍返回工具内部异常 `TypeError: d.on is not a function`，无法接入自动化端口；见 [连接记录](test-results/wechat-automation.json)。这与页面模板的编译结果分开记录。微信工具实际打开由用户确认；**微信内逐项点击、真机相册授权、好友卡片发送及真机字体呈现没有被自动化实机验证**，对应适配代码已通过单元测试，H5 完整闭环已通过真实后端验证。
