| 原型 | 实现 | 内容 |
|---|---|---|

用户确认保留现有格式能力，支持 PDF / DOCX / TXT / Markdown / 公开网页；不会按旧原型新增 DOC 或知识库视频导入。K06 保留默认联网开启；准备范围后仍需多主题确认。H5 原始来源可以打开新窗口，小程序沿用可用的复制来源链接操作。

## 本机分类行为

文件夹、单份资料所在文件夹及最近使用按用户 ID 单独保存。页面刷新可恢复，切换账号不显示上一账号的分类。删除文件夹只移除本机分类，资料归入「未分类资料」，不发送服务器资料删除请求。

文件夹不跨设备同步，清除本机缓存会清除分类，服务器资料仍保留。该限制在 K01 / K03 中明确展示。资料上传、重建、问答、出题继续调用原有后端；本次没有修改后端源码、迁移或业务数据库结构。

## 复现与查看

在 frontend 执行 `npm run typecheck`、`npm test`、`npm run build:h5`、`npm run build:weapp`。最终微信产物为 `frontend/dist`，在开发者工具中打开 `frontend` 并普通编译，进入「我的 → 私有知识库」。

原型测试使用 `playwright.knowledge-prototype.config.ts`；真实存储闭环使用 `playwright.knowledge-prototype-regression.config.ts`，需独立启动 `backend/tests/serve_knowledge_e2e.py`。这类隔离测试服务器不与重置同一测试库的 pytest 并发运行。模型/搜索均为明确的测试替身，未追加真实供应商付费评测。
