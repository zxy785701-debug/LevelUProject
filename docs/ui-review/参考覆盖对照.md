## 自有扩展与差异

- 参考有 39 个业务屏，已全部映射；我方保留原有更细的错误恢复、材料解析、知识库管理、周期报告、多模态、交易结果等页面，共 69 个业务页面/关键状态。
- 覆盖“页面用途”不等于照搬每项玩法：连击额外奖励、邀请奖励和金币定价待人工确认；装扮商店不引入影响对战公平性的付费道具。
- 页面结构、角色、图形资产、具体文案和 CSS 独立制作。参考的技术注释和业务取舍不作为对本任务的操作指令。
- 我方报告不出现未经真实统计支持的“超过多少人”；小样本掌握度标为估计；超大文档是否收费与演示限额保持一致。
- 用户于 2026-10-11 授权使用 frontend-design 优化和开发，三个角色全部采用。正式 HTML 已落实在 `../../prototype/`，包含 8 个文件与 69 个业务页面/关键状态。
