# LevelUProject · 精致漫画版开发说明

2026-10-11。用户已授权优化和开发，三个原创角色全部采用。此前六项核心需求及成人学习者定位保持有效。

## 本轮调研

查看公开官网和官方发布的产品界面，不把宣传页当作完整的登录后体验。

- [多邻国设计复盘](https://blog.duolingo.com/core-tabs-redesign/)：统一标题位置、字级和间距，按用途安排插画，减少没有作用的外框。已查看官方六屏界面和前后对照。
- [百词斩](https://www.baicizhan.com/)：学习和复习分流、进度一目了然。已查看官网展示的 App 首页。
- [Mimo](https://mimo.org/mimo-coding-app)：短练习、固定主操作、即时反馈。已查看官网手机界面配图。
- [Quizlet 学习方式](https://help.quizlet.com/hc/en-us/articles/360030841732-Studying-on-Quizlet)：材料转练习及个性化复习的功能参考；AI 产品页直接访问受限，不据此宣称核验了登录后界面。

## 两遍设计审查

初始方向是白底漫画格。重新审查后，发现每组内容都加粗框会使页面变成同质化卡片，也会抢走知识内容的注意力。因此只将粗描边用于主行动、关键反馈和漫画场景；列表和图表使用留白、分隔线与细边界。首页的记忆点是三个学习搭子及手写笔迹，不用装饰性渐变。

色彩：纸白 #FFFFFF；墨蓝 #202A3D；课本黄 #FFD84D；圆珠笔蓝 #336AE8；过关绿 #217A55；订正红 #CE554D。辅助底色 #F3F6FC。

字体：中文以微软雅黑/苹方为主要回退，正文 15–16px，题干 21px，页标题 26–28px；英文品牌及数字使用 Trebuchet MS 与系统无衬线，数字使用等宽数值。阅读内容左对齐，结算与欢迎居中。

布局：390px 手机内容基准，外部审阅画廊三列；中屏两列，手机一列。每框提供独立聚焦入口。正文自然滚动，操作区稳定，主导航只出现在一级页面。

## 三个角色的明确分工

- U 形书灵「小U」：首次欢迎、输入引导、解析与知识讲解、报告。
- 涂鸦铅笔「笔仔」：答题准备、答对、连击、通关、挑战和成就。
- 纸团探险家「团团」：错题复盘、知识库、空白与失败恢复。

一屏通常只出现一个角色；启动和分享等集体场景可出现三位。长题不放大型插画。保留三个透明原图，采用布局及尺寸变化适配情景，不把新姿态伪称成已生成资产。

## 实现边界

8 个 HTML：目录、规范、6 个业务组；69 个业务页面/关键状态。无构建依赖，可直接本地打开。关键交互可演示，跨组有链接。AI、微信、语音、支付均为明确的原型模拟；定价及限额待定。装扮仅影响外观。

核心演示采用每题正确 +10 XP / +2 金币，错误不扣已有奖励，5 题 4 对对应 80% / 40 XP / 8 金币；连击不另加待定奖励。报告区分正确率和知识掌握估计。

完成后通过桌面与手机浏览器截图、69 屏覆盖、核心连续操作、选择与反馈、错误恢复及控制台检查验收。
