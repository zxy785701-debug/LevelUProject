## 三、建议视觉方向：课本边角里的闯关漫画

从《阿衰》提取校园日常、夸张表情、粗墨线、漫画分格和随手涂鸦的氛围。角色提议使用原创学习搭子；上一轮的小鱼形象已撤回，本轮重新探索 U 形书灵、涂鸦笔同学、纸团探险家三个独立方向，候选暂称“小U”。

漫画感主要用于首页、反馈、结算、分享四个时刻。题干、选项、知识讲解和数据图表使用清楚的排版。每屏只有一处主要视觉焦点；文字和控件保持水平，局部贴纸与角色可以轻微倾斜。

### 色彩

| 角色 | 颜色 | 使用方式 |
| --- | --- | --- |
| 纸白 | `#FFFFFF` | 阅读和答题的主要底色 |
| 墨黑 | `#26211F` | 文字、漫画轮廓、硬边阴影 |
| 课本黄 | `#FFD84D` | 主按钮、当前关卡、重点标记 |
| 圆珠笔蓝 | `#4D8FFF` | 选中项、链接、学习搭子 |
| 过关绿 | `#68BA88` | 正确反馈、已完成状态 |
| 订正红 | `#EB7465` | 错误反馈、待巩固标记 |

浅色背景由上述色彩降低饱和度或叠加白色得到。彩色底上的文字以墨黑为主，状态同时提供图标和文字。

### 字体与控件

- 标题：中文粗黑体，正式 HTML 优先使用本地可用的微软雅黑粗体/苹方中粗；字号 24–28px。
- 题干：20–22px，适当加粗。正文与选项：16px，行高约 1.6。辅助信息：12–14px。
- 漫画边框约 2–3px，主按钮采用约 4px 的偏移硬边阴影，点击时表现为被按下。
- 选项保持规整的大点击区域；圆角比漫画贴纸克制。正文段落与图表无需全部包进厚边卡片。
- 用漫画格推进学习故事：提出疑问 → 尝试解答 → 搭子讲解 → 收获知识。
- 文案示例：“今天想搞懂啥？”“这题拐了个弯，一起拆开看。”“这一关，拿下！”幽默放在情绪反馈，操作名称直接说明用途。
- 尊重减少动态效果设置；动画只在选项提交、获得奖励、完成关卡时短暂出现。

## 四、信息结构与核心流程

主导航建议为：**闯关 / 复盘 / 我的**。

- 闯关：一个主要输入框，下方提供文档、网页、视频入口；私有知识库作为扩展材料入口。
- 复盘：学习概览、历史、错题与报告。分析不是电脑端后台。
- 我的：学习档案、知识库入口、挑战入口、账户、会员及设置。
- 作答和报告详情页面隐藏主导航，保持当前任务集中。

```text
输入学习主题/长文本 ─────────────────────┐
文档/网页/视频 → 解析 → 确认材料与来源 ──┤
                                      ↓
                           AI 获取知识并生成 3–5 题
                                      ↓
                           本轮关卡 → 逐题作答
                                      ↓
                           对错反馈 + 正确答案 + 讲解
                                      ↓
                             继续下一题 / 完成本轮
                                      ↓
                           结算 → 知识总结与复盘报告
                                  ↙              ↘
                          分享海报与好友         个人学习中心
                                                ↓
                                    历史 / 知识分析 / 错题重温
                                                ↓
                                         再次闯关与周期报告
```

主题输入不强制经过材料确认，直接开始生成。文档与链接解析后需要确认学习范围。题量和难度置于可折叠设置，默认 5 题；本轮关卡页提供直接开始，不设计冗长关卡地图。

## 六、关键交互提议，待本轮整体确认

1. 单选/判断选中即判题并锁定本题，多选先勾选再点击“提交答案”；所有题目都立即给出正确答案和讲解。
2. 答错可以继续下一题；建议不扣已获得的 XP，当前题不获得奖励。原型演示规则为每题答对 +10 XP、+2 金币，无额外通关奖励。5 题答对 4 题，对应 80% 正确率、40 XP、8 金币。
3. 讲解先显示核心解释与易错点，完整讲解可展开，保留查看来源与下一题。答错的选项和正确选项同时用文字/图标标明。
4. 小程序题面以 390px 宽为设计基准，允许长题滚动；主操作固定在题面下方安全区。微信顶部状态栏、胶囊和底部安全区均预留空间。
5. 所有单人核心题目均有即时反馈。社交 PK 提议赛中显示作答状态，完整解析赛后展示，以免对手提前看到答案；这一差异仅适用于扩展 PK。
6. 报告的正确率按正确题数计算；知识点掌握度另按对应知识点答题表现估计，明确“本轮估计”，不把单轮样本包装成确定的长期能力。
7. 分享海报包含学习主题、总结金句与小程序码位置，不展示排名；正式小程序码、价格、限额和付费权益均用明确占位或演示值。
8. 游客先体验核心流程，保存跨设备学习档案、好友挑战等需要身份的动作再触发微信登录。
9. 联网/解析展示真实阶段语义，不用持续上涨的虚假精确进度；报告生成失败不影响基础统计与历史答案。
