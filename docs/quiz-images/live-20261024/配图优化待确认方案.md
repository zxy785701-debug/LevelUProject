# 配图优化方案（2026-10-24 已获用户批准）

真实测试发现：直接将题干 JSON 放进生图 Prompt，会被模型画成包含题目和伪答案的文字海报。参考本轮 success/apple-real.png。需要先提炼纯画面，再调用生图模型。

## 拟执行步骤

1. 增加批量画面描述步骤：一轮所有题目由现有文字模型统一转换为逐题视觉描述，正常情况下每轮增加一次文字模型调用。仍遵循现有有界调用/重试预算。
2. 文字模型只接收题干、主题和知识点；不接收正确答案、选项或解析。输出严格映射题目 ID，英语单词优先提取具体实物，历史/地理生成明确场景。描述只表达画面，禁止复述题目、制作海报或加入答案文字。
3. 生图模型只接收纯画面描述及简短风格约束，不再接收题干 JSON。继续使用 qwen-image-2.0、512×512、每题一次请求、最多 5 并发。
4. 同一任务恢复复用已保存的画面计划，避免重复调用。规划失败时保持文字出题成功，并给出配图未完成提示；不会回退到已知效果不合格的题干海报 Prompt。
5. 先补后端失败测试并修复到通过，再用一张真实图片验效果，通过后进行完整五题并发、COS、浏览器、跨登录历史及重闯复用验收。
