## 本轮修复

1. 百炼实际返回 `dashscope-0484.oss-accelerate.aliyuncs.com`。扩展严格的可信结果域名校验，仍拒绝伪装域名、其他 OSS 桶、非 HTTPS 和异常端口。
2. 原题干 Prompt 被画成文字海报。经用户批准，现有文字模型先批量生成纯画面描述；不输入选项、正确答案或解析，生图不再接收题干 JSON。009_image_plans 保存描述及状态，恢复复用，失败正常发布文字。
3. 五请求同时发送触发上游限流。经用户批准，010_image_dispatch 用 MySQL 短事务为 API/Worker 共享预订发送时刻，默认间隔 0.55 秒。连接准备完成后才等待发送，过期名额重新排队，防止事件循环阻塞后请求扎堆。未发出的预留请求取消/超时会退额；实际发出的失败请求仍计入当天次数，不自动重发。

官方当前北京 qwen-image-2.0 上限为每秒 2 次，请求频率与在途并发是两个限制。[阿里云限流文档](https://www.alibabacloud.com/help/zh/model-studio/rate-limit)。
