# Proposal

## Why

首页主题出题目前直接依赖模型已有知识，容易误解新概念的领域，也容易忽略娱乐文化的实际语境。需要同时理解关键词和用户指定网页，由 AI 自主取得适合当前学习目标的资料，在用户确认范围后生成可追溯的题目，并清楚标识无法联网核实的结果。

## What Changes

- 同时支持关键词搜索和网址正文提取；使用 LangChain 官方 `langchain-tavily` 包，将 `TavilySearch`、`TavilyExtract` 一同提供给检索 AI，由其根据输入与工具结果决定调用方式和后续动作。
- 按知识复杂度、歧义、资料充分程度与时效要求动态选择摘要或正文、搜索深度、结果数量、提取深度和必要的时间/来源限制。不能把工具参数固定为适用于所有主题的同一组合。
- 兼顾国内外资料：按主题选择中文、英文或双语关键词。全球知识不限制地域，国家使用可用的搜索偏向，城市通过查询地名及结果地域核对处理，不宣称城市硬筛选或根据回答语言猜测用户所在地。
- 首页主题默认尝试检索，每次先展示含义、领域、方向、知识点和来源概况供用户确认，再出题。网址输入进入网页材料准备，取得实际正文并保留“是否联网补充”的选择；文档和视频保留现有解析方式。
- 网页正文读取及材料联网补充统一复用两项 Tavily 工具。关闭补充时只能读取指定网页或既有材料，不能擅自扩展搜索；不增加其他供应商的自动回退链。
- 依据已确认范围生成题目，独立检查引用存在及片段支持，保存真实文本、来源和时间。未读取的正文、AI 推测和服务商合成答案不能充当已取得的证据。
- 检索失败、未配置或依据不足时自动降级为“未联网核实”，仍须确认范围；只有网址且原页面不可读、无法确定学习内容时明确提示补充主题或正文，不能假装依据该页面出题。
- 准备与主题生成采用有状态后台任务，展示检索、读取、等待额度、出题及校验进度；保留账号限流，对实际模型请求、工具次数、页面数、期限和内容体积统一设限。
- 来源状态贯穿讲解、历史、错题及复盘。示例主题只用于验收，不建立特定名称分支或专用生产题库。
- **BREAKING**：首页主题必须先准备并确认范围，旧的纯 `text` 生成请求返回确认提示；主题生成提交改为返回可查询的操作，成功后从原操作取得 Session。材料接口、历史学习和服务端判分规则保持兼容。
- 本次补齐原始文档中延后的联网能力，沿用实际已有的账号、数据库和服务端判题实现。

## Capabilities

### New Capabilities

- `learning-scope-confirmation`：关键词/网址输入、领域消歧、方向选择、逐次确认及材料范围边界。
- `quiz-evidence-grounding`：自主检索与提取、动态参数、地域相关性、真实来源与题目依据校验。
- `quiz-generation-reliability`：自动降级、后台任务进度与恢复、统一调用预算、账号隔离及历史兼容。

### Modified Capabilities

无。已通过 `openspec list --specs` 确认当前没有主规格；以上为现有实现新增行为的首次规格化。

## Impact

- 后端：`backend/app/services.py`、`llm.py`、`models.py`、`config.py`、`accounts/`、`materials/` 与新增 `quiz_grounding/`；增加准备记录、额度和迁移，扩展后台操作进度与题库 JSON 快照。
- 前端：维护中的 `frontend/`；输入识别、网页预览、学习范围、真实进度、查询恢复、来源与历史展示。`frontend-comic/` 不在本次范围。
- 依赖：增加并锁定与现有 LangChain 兼容的 `langchain-tavily`；使用 LangChain Agent 及其所需运行时，保留 DeepSeek、Taro、FastAPI、MySQL，不引入向量库或长期公共知识库。
- 配置：后端 Tavily 凭证、工具参数边界、模型调用与任务期限；Jina 不再作为新网页读取/搜索路径，不擅自移除其他仍在使用的配置。
- 验证：覆盖两个用户示例、中英资料、简单/复杂知识、纯网址/网址加说明、复杂网页、动态参数、地域、提取失败、限流与引用核对。真实服务质量在实施阶段验证。

本次仅修订提案、设计、规格与实施清单，不执行开发、依赖安装或付费服务评测。
