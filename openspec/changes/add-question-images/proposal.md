# Proposal

## Why

纯文字关卡缺少直观记忆线索。用户需要在闯关前主动选择配图，用英语实物图、历史地理和动植物插图辅助学习，同时保留现有文字出题的可靠性。

## What Changes

- 所有主题、材料和知识库出题增加默认关闭的生成图片选项。
- 审核通过的题目按题并发调用 qwen-image-2.0，生成 512×512 图片并上传腾讯云 COS。
- 题目快照保留可选图片 URL；答题、历史、报告解析和错题复习统一展示，重闯复用。
- 每身份每日默认 20 次实际生图请求；失败计数、上海自然日重置、剩余额度部分生成、幂等恢复防重复扣减。
- 图片失败或配置缺失只影响配图，文字题目正常发布，并返回友好说明。
- 追加配置样例、增量迁移、TDD 证据和运行说明；真实 COS 联调待用户配置后进行。

## Capabilities

### New Capabilities

- `question-illustrations`: 可选题目配图的生成、存储、额度、恢复、降级和跨学习页面展示。

### Modified Capabilities

无。已有范围确认、依据审核、判分、奖励及生成兼容要求保持有效。

## Impact

后端新增独立配图模块和增量 MySQL 表，扩展题目公开/持久化 DTO，接入普通生成与知识库执行器。前端增加设置组件和共用图片展示组件。新增依赖 cos-python-sdk-v5；复用现有 httpx、Pillow 与百炼北京空间配置，不替换 DeepSeek 出题模型。
